# WeJoinLife - Multi-Seller Marketplace

## Architecture
- **Backend:** Spring Boot 4.1.1 (Java 25) with `JdbcClient`
- **Frontend:** Next.js 15 (App Router, Tailwind CSS, Shadcn UI, Zustand)
- **Database:** MySQL / PostgreSQL (existing database)

## Quick Start
1. Run `npm run dev` from root to start both backend & frontend concurrently.
2. Frontend: http://localhost:3000
3. Backend API: http://localhost:8080
